# Contributing to Awesome German News

Thank you for your interest in contributing to Awesome German News! This document provides guidelines for contributing to this list.

## Guidelines

### General

- Make sure your contribution is useful and relevant to the theme of German news, RSS feeds, and reading practice tools
- Search previous suggestions before making a new one to avoid duplicates
- Make an individual pull request for each suggestion
- Use the following format: `[Name](link) - Description.`
- Additions should be added to the relevant category in alphabetical order
- New categories or improvements to the existing categorization are welcome
- Keep descriptions short, simple, and unbiased
- Descriptions should not be marketing taglines or promotional
- Check your spelling and grammar
- Make sure your text editor is set to remove trailing whitespace

### Quality Standards

Only suggest resources that you have used yourself or can vouch for. This helps ensure quality.

News sources should be:
- Reputable and professional
- Regularly updated
- Primarily in German or with significant German content
- Accessible (free or widely available)

Tools and apps should be:
- Functional and actively maintained
- Useful for German learners or news consumers
- Well-documented

### Pull Request Process

1. Fork the repository
2. Make your changes in your fork
3. Ensure your changes follow the guidelines above
4. Submit a pull request with a clear description of your changes
5. Be prepared to make adjustments based on feedback

### What NOT to Include

- Resources that are not primarily about German news or language learning
- Paywalled content that requires expensive subscriptions (unless it's a well-known major publication)
- Abandoned or unmaintained projects
- Resources with primarily promotional content
- Non-German language resources (unless they're translation/learning tools)

## Questions?

If you have questions or need clarification, feel free to open an issue for discussion.

Thank you for contributing!
